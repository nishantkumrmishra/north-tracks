03 // CORE ENGINE ARCHITECTURE SPECIFICATION
+ + + + FEATURE 01 // AUDIO PIPELINE

Akamai 320k Stream Extraction

Extracts authentic 320kbps AAC-LC studio audio directly from CDN edge clusters using DES-ECB stream decryption and bitrate rewriting, preserving original dynamic range without re-encoding.

+ + + + FEATURE 02 // VISUAL IDENTITY

Dual-Tier Artwork Verification

Queries Apple iTunes HD Search API for official 600×600 and 1000×1000 master covers, with automated fallback to JioSaavn's 500×500 high-resolution CDN repository.

+ + + + FEATURE 03 // INTELLIGENT ROUTING

Category-First Folder Sorting

Analyzes track artist fingerprints and Devanagari script heuristics to route files directly into genre folders (Indian Indie, Bollywood, Punjabi, Pop, Rock, Hip-Hop) with companion .m3u playlists.

+ + + + FEATURE 04 // USER EXPERIENCE

Zero-Jitter Single-Screen Dashboard

Cleans the terminal screen on launch, updates progress in-place without terminal scroll jumping, and provides clean shortcut controls with safe Ctrl+C atomic cancellation.

04 // COMMAND REFERENCE SHORTCUTS
Input Command Description & Action
:stats Inspect library category breakdown, total track counts, and disk space usage.
:repair Scan existing audio files, fix broken tags or names, and re-download official HD artwork.
:dest Switch the default music storage directory.
:exit Cleanly close North Tracks.
Ctrl+C Safely interrupt an active stream without leaving half-written or corrupted files on disk.
